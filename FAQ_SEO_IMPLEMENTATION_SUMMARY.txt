🚀 HOW TO MAXIMIZE SEO IMPACT:

1. LINK TO FAQs FROM BLOG POSTS:
   ─────────────────────────────
   In your blog posts, import and use the FAQ reference component:

   import FAQReference from '@/app/components/FAQReference';

   // Inline link
   <p>
     Learn more about <FAQReference index={5} /> in our FAQ.
   </p>

   // Callout box
   <FAQReference
     index={13}
     title="Understanding co-op board approval"
     variant="callout"
   />

   // At end of post
   import { RelatedFAQs } from '@/app/components/FAQReference';
   <RelatedFAQs faqIndexes={[0, 5, 13, 20]} />


2. ADD NEW FAQs EASILY:
   ────────────────────
   Open: /workspace/app/data/faqData.ts
   Add to the faqItems array:

   {
     category: "Your Category",
     question: "Your question here?",
     answer: "Your answer. Can use <strong>HTML</strong> formatting.",
     popular: true,  // Optional: shows in "Most Popular"
     relatedIndexes: [5, 10]  // Optional: link to related FAQs
   }

   The sitemap and schema update automatically! ✨
